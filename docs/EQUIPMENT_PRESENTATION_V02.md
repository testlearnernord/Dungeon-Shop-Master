# Equipment presentation V0.2

Each gear product has distinct physical stock geometry. The existing T1 Leather Vest is retained. Seven original replacement/new GLBs are generated by `npm run assets:gear` and committed as runtime inputs; no external dependencies or assets are required. The old Python generator no longer owns the Sword & Shield file.

- T1/T2 Sword & Shield include both a real shield and blade as one merchandise unit.
- T1/T2 spears and staves have real narrow, long silhouettes, separate blade/crystal, metalwork and grip details.
- T2 Ghoul Leather Vest features reinforced hide panels, stitches, buckles and rivets.
- T2 has brighter metal fittings, not a generic glowing legendary effect.
- The shop and carried merchandise clone the same item-specific mesh; no new economy, colliders or stock authority.
- Long weapons have a bounded shelf arrangement; sword-and-shield sets stack by thickness. Equipped spear tips and staff orbs follow tier and reset during historical replay.

This is an authored low-poly art pass, not a claim of premium sculpting or human visual sign-off. Inspect the actual shelf, carried products and equipped heroes before closing art acceptance.
